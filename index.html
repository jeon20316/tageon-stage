처음 연결하는 방법
  1. developer.spotify.com/dashboard 에 로그인하고 Create app을 눌러요.
  2. Redirect URIs에 위 주소를 붙여넣고, API 항목에서 Web API를 체크해 저장해요.
  3. 만든 앱의 Client ID를 복사해서 위 칸에 붙여넣어요.
  4. 스포티파이 연결을 누르고 로그인한 뒤, 스포티파이에서 노래를 틀어요.
  5. 연결 후 권한 오류가 나면 앱 설정의 User Management에 내 스포티파이 이메일을 추가해요.
